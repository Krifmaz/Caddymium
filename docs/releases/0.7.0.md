## Caddymium 0.7.0

Caddymium now keeps your sites up on its own, and the panel tells you plainly when something needs you.

- **Safe Caddy updates.** An update only counts when the new Caddy is serving: the admin API and every listener answer. Otherwise the panel kills a stuck process, goes back to the previous build (or the image's own Caddy) and tells you.
- **Restarts that work.** Restart Caddy checks that Caddy serves again within 30 seconds, tries once more, then rolls back. No container restart needed.
- **Watchdog.** If Caddy stops answering for a minute, the panel restarts it and notifies you; the sidebar shows when it last did.
- **No surprise changes.** Updates never switch on new protections for sites you already have. New defaults show up as a suggestion on the Security page that you can turn on per site or for all.
- **Clear errors.** Every error says what happened and what to do, and has a Copy button.
- **Groundwork for the shared kit.** The server now serves release notes, health notices (Caddy not serving, a failed update, a full or read-only data folder), bug reports, crash logs and diagnostics; the new web app that shows them follows.
